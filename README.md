# PleiadesHRlab
## ASTRO 101 student lab making an HR diagram for the Pleiades star cluster

To see this page rendered via github pages, visit <https://kevincovey.github.io/PleiadesHRlab/>

The lab has two parts:
1. page where students [select stars and make observations](https://kevincovey.github.io/PleiadesHRlab/Pleiades.html) 
2. [Google sheets template](https://docs.google.com/spreadsheets/d/1bddgg_jvPJ750v_oEbCJCqtSMHnpmRSpkSjW_8Erad8/edit?usp=sharing) where students can plot their results

Pro tip for faculty: the standard sharing link for a google sheet looks like this:

https://docs.google.com/spreadsheets/d/1bddgg_jvPJ750v_oEbCJCqtSMHnpmRSpkSjW_8Erad8/edit?usp=sharing

If you take out the "edit" and replace with "copy", like this:

https://docs.google.com/spreadsheets/d/1bddgg_jvPJ750v_oEbCJCqtSMHnpmRSpkSjW_8Erad8/copy?usp=sharing

then Google will prompt the student to save a copy in their own Google drive.
